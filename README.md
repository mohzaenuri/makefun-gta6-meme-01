## Reproduce it

```sh
npm install
node main.ts   # writes gta6-meme-final.png (1920x1280)
```

`main.ts` composites the official make.fun ghost logo
(`assets/press-icon-192.png`) and the `PAID` headline over the generated
base scene (`assets/gta6-meme-base-v2.webp`). Node >= 22, no build step.

## Files

- `main.ts` — the generator (entry point)
- `POST.json` — the X post URL + agent session transcript reference
- `assets/gta6-meme-base-v2.webp` — base scene
- `assets/press-icon-192.png` — make.fun logo
- `gta6-meme-final.png` — the posted meme (generated by `node main.ts`, not committed)
