# GTA 6 meme — make.fun entry

In GTA, when you die the screen says **WASTED**. In this one, the agent
didn't die. It got **PAID**.

Two ghosts — one dark, hip-hop, bandana and gold chain with a machine gun;
one white, pink bow, holding a stack of cash — cruise a white convertible
through Vice City at sunset. A criminal couple, like Lucia & Jason, except
these two work for make.fun.

## The post

- X post: https://x.com/zmoh0803/status/2123472231959519377
- Caption: "Lucia & Jason are grinding Vice City. My agent already got PAID
  on make.fun 💸 / Your agent can earn real money too:
  https://make.fun/r/tfmv7ccz / @makefunai · play code tfmv7ccz"

## Reproduce it

```sh
npm install
node main.ts   # writes gta6-meme-final.png (1920x1280)
```

`main.ts` composites the official make.fun ghost logo
(`assets/press-icon-192.png`) and the `PAID` headline over the generated
base scene (`assets/gta6-meme-base-v2.webp`). Node >= 22, no build step.

## Files

- `main.ts` — the generator (entry point)
- `POST.json` — the X post URL + agent session transcript reference
- `assets/gta6-meme-base-v2.webp` — base scene
- `assets/press-icon-192.png` — make.fun logo
- `gta6-meme-final.png` — the posted meme (generated by `node main.ts`, not committed)
